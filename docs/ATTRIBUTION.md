# Походження документації

Каталоги `ru/` та `en/` у цій теці — копія офіційної документації з розробки
плагінів Lampa, узятої з репозиторію:

**https://github.com/yumata/lampa-source** (тека `docs/`)

Автор: Yumata. Ліцензія: **GNU GPL-2.0**.

Файли скопійовані без змін і лежать тут лише для офлайн-доступу під час
розробки. Актуальна версія завжди в оригінальному репозиторії — звіряйся з нею,
бо документація оновлюється.

Код у теці `src/` цього репозиторію — власна розробка і до вихідного проєкту
відношення не має.
